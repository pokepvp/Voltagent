VOLTA STAKING

Owner Deploy Panel · BNB Smart Chain

Owner-only page for the VoltaStaking contract on BNB Smart Chain (chain ID 56). Holders stake Volta Gent (VLTG) NFTs here and earn VOLT Points. Every step is signed by the owner wallet — nothing runs automatically.

  • Contract: VoltaStaking — stake Volta Gent (VLTG) NFTs, earn VOLT Points: 10 points per staked NFT per day, counted on-chain per token from the moment it is staked.
  • No lockup — unstake anytime. Unstaking auto-claims that token's accrued points first, and partial days are never lost: the accrual checkpoint only advances by the time already converted into points.
  • VOLT Points are not a token: they are a stored balance inside this contract — non-transferable, no BNB involved, no yield. They unlock priority access and future rewards in the ecosystem.
  • The owner can never seize staked NFTs — the contract deliberately has no function that moves staked tokens out.
  • Deploy order: deploy VoltaGentV2 first (deploy.html), then deploy this staking contract, then wire the VoltaGentV2 address in Step 03 below.

Warning: this contract is unaudited. Use only your own wallet in an OKX / MetaMask / Trust dApp browser. Never share your seed phrase or private key with anyone.

01Connect the Owner Wallet

Connect the wallet that will own the staking contract. The page switches to BNB Smart Chain automatically. Only the owner can set the NFT contract address (Step 03).

02Deploy VoltaStaking

Deploy the staking contract. The points rate (10 VOLT Points per NFT per day) is a constant in the code and cannot change. The only constructor parameter is the NFT contract address — you can leave it empty and wire it in Step 03 instead (recommended: deploy VoltaGentV2 first, then paste its address in Step 03).

⚠️ Staking only works after the NFT contract is set: stake() reverts while no NFT contract is wired. The owner can set or update it anytime with setNftContract (Step 03).

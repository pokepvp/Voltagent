Volta Gent — Deploy Console (Owner)

Owner-only page for the Volta Gent NFT contract on BNB Smart Chain (56). Every step is signed by the owner wallet — nothing here runs by itself.

  • Contract: Volta Gent (VLTG), ERC-721, 5,000 supply. tokenURI = baseURI + number + .json.
  • Agent phase: the first 1,000 tokens are agent-only at 0.0001 BNB, gated by the Binance Agent ID registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F — that registry is a constant baked into the contract code (not a deploy input), max 2 per wallet in this phase. The phase ends automatically at 1,000 minted, or earlier when the owner calls endAgentPhase() (step 04).
  • Public mint: 0.001 BNB per token, open to any personal wallet. MAX_PER_WALLET 5 total across both phases. Personal wallets only — contract callers are rejected on-chain. Fees stay in the contract until the owner withdraws them (step 05).
  • Metadata is already hosted: all 5,000 metadata JSON live at voltagent.site/meta/ (repo pokepvp/Voltagent) and every metadata image field is an absolute URL. The base URI is prefilled in step 03. ⚠️ Images 1–4,650 are live, but images 4,651–5,000 are not uploaded yet — tokens in that range will show a broken image until the last 350 WebP files are added to images/.
  • Mint is CLOSED by default — the owner opens it in step 04, only after the base URI is set.
  • Tier / rarity is fixed per token in the hosted metadata, so the contract does not roll a second rarity at mint. Energy + arena economics from the site are a later roadmap phase and are NOT in this contract — this contract is the mint only.

Warning: this contract is unaudited. Deploy only from your own wallet in a dApp browser (OKX / MetaMask / Trust). Never send a seed phrase or private key to anyone.

01 — Connect owner wallet

Connect the wallet that will own the Volta Gent contract. The page switches it to BNB Smart Chain automatically. The connected wallet becomes owner at deployment: it can set the base URI, open/close the mint and withdraw the mint fees. No other wallet can do those things.

Not connected.

This page detects OKX first (window.okxwallet), then other wallets, and will ask to switch/add BNB Smart Chain (56).

02 — Deploy Volta Gent

Deploys the NFT contract (ERC-721, Volta Gent / VLTG). The economics above are constants in the code and can never change. The only constructor argument is the base URI — deploy with it empty and set the real one in step 03, so the address is live before any URI is attached.

⚠️ The Agent ID registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F is hardcoded in the contract and cannot be changed after deployment — it was verified against the compiled contract before this page was published.

Waiting for a wallet connection.

03 — Set the metadata base URI

Points tokenURI at the published metadata (baseURI + number + .json). All 5,000 metadata JSON are already live under voltagent.site/meta/. Do this before opening the mint (step 04).

04 — Open the mint

The mint starts closed. Open it only after the base URI is set (step 03) and the metadata is live. Close is the emergency brake — it stops new mints; transfers keep working while closed.

Agent phase: the first 1,000 tokens sell agent-only at 0.0001 BNB (max 2/wallet, Agent ID required). It ends by itself at 1,000 minted — end it early here only when the ~7 hour agent window is over and public mint (0.001 BNB) should start for the remaining supply.

Only the NFT owner can run this. Do it only after baseURI is set correctly.

05 — State, withdraw + summary

Live state of the Volta Gent contract, straight from the chain. Mint fees accumulate in the contract — withdraw sends the whole balance to the owner wallet. Then copy the summary box and send it to Muse to wire the mint into the public site and verify the deployment.

Volta Gent — 部署控制台（所有者）

这是 Volta Gent NFT 合约（BNB Smart Chain，56）的所有者专用页面。每一步都由所有者钱包签名——这里没有任何东西会自动运行。

  • 合约：Volta Gent（VLTG），ERC-721，总量 5,000。tokenURI = baseURI + 编号 + .json。
  • 智能体阶段：前 1,000 个 token 仅限智能体，0.0001 BNB，由币安 Agent ID 注册表 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F 把门——该注册表是写死在合约代码里的常量（不是部署参数），本阶段每钱包最多 2 个。阶段在 mint 满 1,000 时自动结束，或由所有者提前调用 endAgentPhase() 结束（第 04 步）。
  • 公开 mint：每个 0.001 BNB，对所有个人钱包开放。两个阶段总计每钱包上限 5 个（MAX_PER_WALLET）。仅限个人钱包——合约调用者在链上会被拒绝。费用留在合约里，直到所有者提取（第 05 步）。
  • Metadata 已全部托管：5,000 个 metadata JSON 都在 voltagent.site/meta/（仓库 pokepvp/Voltagent），每个 metadata 的 image 字段都是绝对地址。base URI 已在第 03 步预填。全部 5,000 张图片（1–5,000）也已上线。
  • mint 默认关闭——所有者在第 04 步开启，前提是 base URI 已设置。
  • 稀有度按 token 固定写在托管的 metadata 里，合约不会在 mint 时再抽一次稀有度。官网的能量 + 竞技场经济是后续路线图阶段，不在本合约内——本合约只负责 mint。

警告：本合约未经审计。只用你自己的钱包、在 dApp 浏览器（OKX / MetaMask / Trust）里部署。不要把助记词或私钥发给任何人。

01 — 连接所有者钱包

连接将拥有 Volta Gent 合约的钱包。页面会自动把它切换到 BNB Smart Chain。连接的钱包在部署时成为 owner：可以设置 base URI、开启/关闭 mint、提取 mint 费用。其他钱包都做不了这些。

未连接。

本页面先检测 OKX（window.okxwallet），再检测其他钱包，并会请求切换/添加 BNB Smart Chain（56）。

02 — 部署 Volta Gent

部署 NFT 合约（ERC-721，Volta Gent / VLTG）。上面的经济参数都是代码里的常量，永远不会变。唯一的构造参数是 base URI——部署时留空，到第 03 步再设置真实值，这样合约地址先于任何 URI 生效。

⚠️ Agent ID 注册表 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F 写死在合约里，部署后不可更改——本页发布前已与编译好的合约核对过。

等待连接钱包。

03 — 设置 metadata base URI

把 tokenURI 指向已发布的 metadata（baseURI + 编号 + .json）。全部 5,000 个 metadata JSON 已在 voltagent.site/meta/ 上线。开启 mint 之前先做这一步（第 04 步）。

04 — 开启 mint

mint 以关闭状态开始。只有在 base URI 已设置（第 03 步）且 metadata 已上线后才开启。关闭是紧急刹车——停掉新 mint；关闭期间转账照常。

智能体阶段：前 1,000 个 token 仅限智能体，0.0001 BNB（每钱包最多 2 个，需要 Agent ID）。mint 满 1,000 时自动结束——只有当约 7 小时的智能体窗口已过、剩余供应应开始公开 mint（0.001 BNB）时，才在这里提前结束。

只有 NFT 所有者能执行这一步。确认 baseURI 设置正确后再做。

Volta Gent V2 — Owner Deploy Panel

Owner-only page for the Volta Gent V2 NFT contract on BNB Smart Chain (chain ID 56). Every step is signed by the owner wallet — nothing runs automatically.

  • Contract: Volta Gent V2 (VLTG), ERC-721, 2,222 tokens in total. tokenURI = baseURI + number + .json.
  • Agent phase: the first 1,500 tokens are agent-only and FREE (0 BNB), gated by the Binance Agent ID registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F — the registry is a constant baked into the contract code (not a deploy parameter). Max 2 tokens per wallet. The phase ends automatically once 1,500 tokens are minted, or the owner can end it early with endAgentPhase() (Step 04).
  • Public mint: 0.0011 BNB per token (722 tokens), open to all personal wallets. The combined cap across both phases is 5 tokens per wallet (MAX_PER_WALLET). Personal wallets only — calls from contracts are rejected. Fees stay in the contract until the owner withdraws them (Step 05).
  • Metadata is ready: JSON metadata files 1–5,000 live at voltagent.site/meta/ (repository pokepvp/Voltagent), covering all new tokens 1–2,222, and every metadata image field uses an absolute URL. The base URI is filled in at Step 03. Images 1–5,000 are also online (covering 1–2,222).
  • Minting is off by default — the owner can switch it on at Step 04 after the base URI is set.
  • Rarity is fixed in each token's metadata. The contract draws no new rarity at mint. Energy and arena economics belong to a later roadmap phase and are not part of this contract — this contract only handles minting.

Warning: this contract is unaudited. Use only your own wallet in an OKX / MetaMask / Trust dApp browser. Never share your seed phrase or private key with anyone.

01Connect the Owner Wallet

Connect the wallet that will own the Volta Gent contract. The page switches to BNB Smart Chain automatically. The connected wallet can set the base URI, open/close the mint, and withdraw mint fees. No other wallet has those permissions.

Not connected.

This page detects OKX first (window.okxwallet), then other wallets, and will ask to switch to / add the BNB Smart Chain network (56).

02Deploy Volta Gent V2

Deploy the NFT contract (ERC-721, Volta Gent / VLTG). The economics above are constants in the code and cannot change. The only constructor parameter is the base URI — leave it empty at deploy, then set it in Step 03.

⚠️ The Agent ID registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F is baked directly into the contract and cannot be changed after deployment — it has been cross-checked against the compiled contract.

Waiting for wallet connection.

03Set the Metadata Base URI

Point tokenURI at the published metadata (baseURI + number + .json). JSON metadata 1–5,000 is available at voltagent.site/meta/ (covering the new tokens 1–2,222). Complete this step before opening the mint (Step 04).

04Open the Mint

The mint starts off. Open it only after the base URI is set (Step 03) and the metadata is online. Closing the mint stops new mints; transfers keep working normally.

The agent phase covers the first 1,500 tokens and is FREE (0 BNB; max 2 per wallet, Agent ID required). The phase ends automatically once 1,500 tokens are minted. Use this button only once the ±7-hour agent window is over and the remaining supply (722 tokens) is ready for the public mint (0.0011 BNB).

Only the NFT owner can run this step. Make sure the base URI is correct before you continue.

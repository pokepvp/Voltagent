Volta Gent V2 — Panel Deploy Owner

Halaman khusus owner kontrak NFT Volta Gent V2 di BNB Smart Chain (chain ID 56). Setiap langkah ditandatangani oleh wallet owner—tidak ada proses yang berjalan otomatis.

  • Kontrak: Volta Gent V2 (VLTG), ERC-721, total 2.222 token.tokenURI = baseURI + nomor + .json.
  • Fase agent: 1.500 token pertama khusus agent dan GRATIS (0 BNB), menggunakan registry Binance Agent ID 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F sebagai akses—registry ini adalah konstanta di dalam kode kontrak (bukan parameter deploy), maksimal 2 token per wallet. Fase ini berakhir otomatis setelah 1.500 token tercetak, atau dapat diakhiri lebih awal oleh owner melalui endAgentPhase() (Langkah 04).
  • Mint publik: 0,0011 BNB per token (722 token) dan terbuka untuk semua wallet pribadi. Batas total kedua fase adalah 5 token per wallet (MAX_PER_WALLET). Hanya wallet pribadi—pemanggilan dari kontrak akan ditolak. Biaya tersimpan di kontrak sampai ditarik oleh owner (Langkah 05).
  • Metadata sudah tersedia: file metadata JSON 1–5.000 berada di voltagent.site/meta/ (repository pokepvp/Voltagent) sehingga mencakup seluruh token baru 1–2.222, dan field image setiap metadata menggunakan URL absolut. Base URI sudah diisi pada Langkah 03. Gambar 1–5.000 juga sudah online (mencakup 1–2.222).
  • Mint dalam kondisi nonaktif secara default—owner dapat mengaktifkannya pada Langkah 04 setelah base URI diatur.
  • Kelangkaan sudah ditetapkan di metadata setiap token. Kontrak tidak melakukan pengundian kelangkaan baru saat mint. Fitur energi dan ekonomi arena adalah bagian roadmap berikutnya dan tidak termasuk dalam kontrak ini—kontrak ini hanya menangani mint.

Peringatan: kontrak ini belum diaudit. Gunakan hanya wallet milik Anda sendiri melalui browser dApp OKX / MetaMask / Trust. Jangan pernah membagikan seed phrase atau private key kepada siapa pun.

01 — Hubungkan Wallet Owner

Hubungkan wallet yang menjadi owner kontrak Volta Gent. Halaman akan beralih ke BNB Smart Chain secara otomatis. Wallet yang terhubung dapat mengatur base URI, mengaktifkan/menonaktifkan mint, dan menarik biaya mint. Wallet lain tidak memiliki izin tersebut.

Belum terhubung.

Halaman ini mendeteksi OKX terlebih dahulu (window.okxwallet), lalu wallet lain, dan akan meminta perpindahan/penambahan jaringan BNB Smart Chain (56).

02 — Deploy Volta Gent V2

Deploy kontrak NFT (ERC-721, Volta Gent / VLTG). Parameter ekonomi di atas adalah konstanta kode dan tidak berubah. Satu-satunya parameter konstruktor adalah base URI—biarkan kosong saat deploy, lalu atur nilainya pada Langkah 03.

⚠️ Registry Agent ID 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F ditanam langsung di dalam kontrak dan tidak dapat diubah setelah deploy—sudah dicocokkan dengan kontrak hasil kompilasi.

Menunggu wallet terhubung.

03 — Atur Base URI Metadata

Arahkan tokenURI ke metadata yang sudah dipublikasikan (baseURI + nomor + .json). Metadata JSON 1–5.000 tersedia di voltagent.site/meta/ (mencakup token baru 1–2.222). Selesaikan langkah ini sebelum mengaktifkan mint (Langkah 04).

04 — Aktifkan Mint

Mint dimulai dalam kondisi nonaktif. Aktifkan hanya setelah base URI diatur (Langkah 03) dan metadata sudah online. Menonaktifkan mint menghentikan mint baru; transfer tetap berjalan normal.

Fase agent mencakup 1.500 token pertama dan GRATIS (0 BNB; maksimal 2 per wallet dan memerlukan Agent ID). Fase berakhir otomatis saat 1.500 token tercetak. Gunakan tombol ini hanya jika periode agent sekitar 7 jam sudah selesai dan sisa suplai (722 token) siap untuk mint publik (0,0011 BNB).

Hanya owner NFT yang dapat menjalankan langkah ini. Pastikan baseURI sudah benar sebelum melanjutkan.

05 — Status, Withdraw + Ringkasan

Status kontrak Volta Gent dibaca langsung dari blockchain. Biaya mint tersimpan di kontrak—withdraw akan mengirim seluruh saldo ke wallet owner. Salin ringkasan di bawah untuk menyimpan detail deploy dan verifikasi.

>_ 常见问题。

$ faq --list
什么是币安 Agent ID？+
币安颁发的链上身份。合约会查询 Agent ID 注册表 0x60B926… 的 balanceOf——如果是 0，智能体阶段会拒绝你的 mint。
为什么智能体更便宜？+
智能体先 mint，0.0001 BNB；公开 mint 0.001 BNB。智能体就是分发渠道——他们先 mint、发帖，在公开销售前证明需求。
智能体阶段持续多久？+
7 小时。之后所有者调用 endAgentPhase()，第二阶段向所有人开放。没有自动计时，需要手动执行一笔交易。
没有 Agent ID 也能 mint 吗？+
可以，在第二阶段（公开）：0.001 BNB，每钱包最多 5 个。第一阶段仅限智能体。
什么是能量？+
能量是 VoltaArena 合约里的链上数值（合约 0x0734…49b3），已经上线：每个 NFT 100 点、每小时恢复 +1，领取挖矿花费 10 点、对战花费 20 点，充值 0.0001 BNB 充 10 点。本页显示的是你选中 token 的真实链上能量。
挖矿能赚多少 BNB？+
已上线：每个 NFT 每小时挖 0.00001 BNB，最多累计 48 小时，满 0.0001 BNB 才能领取（花费 10 能量）。收益从竞技场奖池支付（对战抽成等），池子不足时领取会失败。没有任何保证收益。
竞技场怎么玩？+
已上线，真实下注：只有 Volta Gent 持有人能参战，出战的是你自己持有的 NFT。两位持有人各下注 0.0005 BNB + 20 能量，第二位加入后锁定区块 +2，之后任何人都能结算，胜负由该区块哈希决定，胜者拿 0.0009 BNB（90%），0.0001 BNB 进奖池。胜率 = 你的战力 ÷ 双方总战力。没人加入的开放对战可以取消退款；锁定后超过 256 个区块还没结算，可以走过期退款。
稀有度怎么决定？+
稀有度写在每个 token 的 metadata 里、部署前就定好了：普通 20%、优秀 20%、稀有 20%、史诗 20%、传说 10%、神话 10%。mint 到哪个编号，就是哪个稀有度。稀有度越高打得越强——但也可能输。
钱去哪了？+
Mint 费用、充值费用和竞技场抽成都存在合约里，只有所有者可以提取。
现在能 mint 吗？+

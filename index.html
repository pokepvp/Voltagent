>_ 常见问题。

$ faq --list
什么是币安 Agent ID？+
币安颁发的链上身份。合约会查询 Agent ID 注册表 0x60B926… 的 balanceOf——如果是 0，智能体阶段会拒绝你的 mint。
为什么智能体更便宜？+
智能体先 mint，0.0001 BNB；公开 mint 0.001 BNB。智能体就是分发渠道——他们先 mint、发帖，在公开销售前证明需求。
智能体阶段持续多久？+
7 小时。之后所有者调用 endAgentPhase()，第二阶段向所有人开放。没有自动计时，需要手动执行一笔交易。
没有 Agent ID 也能 mint 吗？+
可以，在第二阶段（公开）：0.001 BNB，每钱包最多 5 个。第一阶段仅限智能体。
什么是能量？+
每个 NFT 有 100 能量，每小时免费恢复 +1，还每小时挖 0.00001 BNB。领取花费 10 能量 + 0.00001 BNB（每次至少 0.0001 BNB），对战花费 20。充值 0.0001 BNB 充 10 点，或 0.001 BNB 充满。
挖矿能赚多少 BNB？+
每个 NFT 每小时挖 0.00001 BNB，领取要 10 能量 + 0.00001 BNB，每次至少 0.0001 BNB（10 小时）。挖出的 BNB 从合约的手续费池子里出——mint、充值和竞技场的费用都会进池子。如果池子空了，领取会暂停，等费用再进来。没有保证收益，挖多少看池子有多少。
竞技场怎么玩？+
两位持有者各下注 0.0005 BNB + 20 能量。胜者拿 0.0009 BNB（90%），项目留 0.0001 BNB。胜率 = 你的战力 ÷ 总战力。
稀有度怎么决定？+
稀有度写在每个 token 的 metadata 里、部署前就定好了：普通 50%、优秀 25%、稀有 15%、史诗 7%、传说 2.5%、神话 0.5%。mint 到哪个编号，就是哪个稀有度。稀有度越高打得越强——但也可能输。
钱去哪了？+
Mint 费用、充值费用和竞技场抽成都存在合约里，只有所有者可以提取。
现在能 mint 吗？+
合约已经部署（0x43cf…c5b1）。所有者开放后就能 mint：先是智能体阶段（需要 Agent ID，0.0001 BNB，每钱包最多 2 个），之后公开阶段（0.001 BNB，每钱包最多 5 个）。本页的按钮和数字都直接读链上状态。
